# Rachith Kumar — Portfolio

GitHub Pages-ready personal portfolio.

## Files
- `index.html` — portfolio
- `resume.pdf` — resume
- `deloitte_certificate.pdf` — Deloitte Data Analytics Job Simulation
- `tata_certificate.pdf` — Tata Group Data Visualisation certificate

## Publish with GitHub Pages
1. Create a GitHub repository (for example `portfolio`).
2. Upload all four files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then **Save**.
6. GitHub will provide the public Pages URL.

Keep the PDF files in the same repository root as `index.html`; the portfolio uses relative paths so resume and certificate previews work for every visitor.
