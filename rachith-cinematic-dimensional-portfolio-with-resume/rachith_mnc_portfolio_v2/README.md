# Rachith Kumar M — MNC / Interview-Ready Portfolio — V2

This version is intentionally designed more like a polished product/engineering portfolio than a resume page.

### Highlights
- Premium dark UI with restrained cyan/violet accent system
- Responsive layout
- Command palette (`Ctrl/Cmd + K`)
- Work filters: All / Analytics / Software
- Case-study style project presentation
- Interactive credential cards
- GitHub and SkillPath links
- Click-to-email contact
- Optional EmailJS form
- Uploaded profile photo and 3 certificates included locally

### Contact form
Replace these in `script.js`:
- `YOUR_PUBLIC_KEY`
- `YOUR_SERVICE_ID`
- `YOUR_TEMPLATE_ID`

The visible email link works without EmailJS.

### Deploy
Upload the entire folder to GitHub and enable GitHub Pages, or deploy it to Netlify/Vercel/Render as a static site.
